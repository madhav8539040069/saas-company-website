# NexaFlow — Client Ready SaaS Website

## Run locally
1. Install Node.js 18+.
2. Open this folder in Terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the Vite local URL shown in the terminal.

## Production build
Run `npm run build`, then deploy the generated `dist` folder to Vercel, Netlify or another static host.

## Before client delivery
Replace NexaFlow branding, copy, pricing, legal text and contact form backend with the client's real details.
